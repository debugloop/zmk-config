This is the config for my keyboard, a [TOTEM](https://github.com/GEIGEIGEIST/TOTEM). It is minimal
and largely self contained regarding the hardware specifics of the board, but utilizes some ZMK
community projects for the keymap's features.

It uses [zmk-nix](https://github.com/lilyinstarlight/zmk-nix) to handle the annoying bits of dealing
with West, Zephyr, etc.
